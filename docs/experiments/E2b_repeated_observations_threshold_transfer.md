- 작성일: **2026-10-20 (Asia/Seoul)**
- 상태: **계획·미실행. 시퀀스 확보·모델 실행·평가 결과를 보고한 문서가 아니다.**
- 상위 계획: [v3 §8.1, §10.3](../surface_guided_gaussian_mapping_research_plan_v3.md)
- 선행 결과: [E0b 관측 감사](E0b_ancestry_causality_audit.md), [E1 오류 분류](E1_error_taxonomy.md), [E2 점수 판별력](E2_signal_discriminability.md)

## 목표와 추가 이유

**반복 유효 관측이 생기는 시퀀스를 확보하고, 개발 구간에서 정한 기준을 새로운 평가 구간에 고정 적용했을 때 정상 후보를 보존하면서 불량 후보도 실제로 거부 대상으로 식별하는지 검증한다.**

E2의 작은 공통 집합에서 P1 AP는 0.4268로 B6의 0.3995보다 높아 제한적 사전 기술 기준을 충족했다. 그러나 동시 2+ 유효 plane 관측 후보는 0개였고, 개발 임계값 52.230은 평가 점수 최댓값 37.589보다 높아 bad recall이 0%였다. 이 결과는 E2의 제한적 기준 실패나 연구 전체 실패로 소급 해석하지 않는다. **E2b는 실제 반복 충돌 판정에 쓸 수 있는 관측과 전이 가능한 운영점을 확보하는 후속 검증**이다.

E2b의 `would_reject`는 고정 후보에 대한 판정 로그다. 실제 Map에서 후보를 삭제하거나 정책별 Map 상태를 갱신하지 않는다. 편입·보류 정책의 geometry/coverage/NVS 효과와 실제 queue 비용은 E3 이후에 검증한다.

## 고정 조건과 시퀀스 확보

1. **주 arm은 관측 시간 확대:** 더 긴 연속 입력과 재방문 구간을 확보한다. 같은 실행 내에서 tracker, KF 선택 규칙, predictor/weights, 후보 생성, 해상도 및 원본 필터를 유지한다. 방법 간에는 동일한 frozen 후보·pose·관측 풀을 사용한다. 입력 범위 확대는 새 baseline run으로 기록하며, E2와 후보 ID나 pose가 같다고 가정하지 않는다.
2. **관측 풀 확장은 별도 arm:** 원본 KF만으로 부족하면 비-KF 또는 추가 raw pair prediction을 읽기 전용 증거로 사용하는 arm을 둔다. 추가 모델 호출, 원본 이미지/pair ancestry, 관측 사용 가능 시각과 pose 연결, 메모리·계산비용을 기록한다. 추가 예측에서 생성된 Gaussian을 공통 후보 풀에 섞지 않는다.
3. **조건 완화로 성공을 만들지 않음:** E2의 confidence·ray matching·시차·가림·깊이 경계·plane 품질 조건을 시작점으로 유지한다. 조건 변경은 개발 구간의 ablation으로 분리하고 평가 전에 고정한다. Fused pointmap을 raw source-disjoint 관측으로 대체하지 않는다.
4. **확보 명세:** 장면·원본 frame 구간·입력 간격·KF 수·pair 목록·모델/코드/입력 hash·관측 정책을 남긴다. 확보 후보와 선택 절차는 개발 자료의 GT 없는 관측 가용성 감사로 정하며, 최종 평가 장면 목록은 평가 전에 고정한다. 평가에서 관측이 부족한 장면도 제외하거나 다른 장면으로 교체해 통과시키지 않는다.

### 유효한 반복 관측의 정의

- 각 관측은 후보의 생성 이미지/pair와 원본 이미지 ancestry가 겹치지 않고, 판단 시점까지 실제로 도착해 있어야 한다.
- 서로 다른 raw prediction event/관측 시점의 증거 2개 이상이 **같은 판단 snapshot과 pose revision에서** 시야·ray 대응·시차·가림·patch 품질 조건을 모두 만족해야 한다. 같은 raw 관측의 복제나 다른 branch를 별도 관측으로 세지 않는다.
- 두 관측 각각에서 같은 방향의 front/free-space 충돌이 확인되어야 한다. 2개 관측이 있다는 사실만으로 거부하지 않는다. 서로 다른 snapshot에서 한 번씩 유효했던 관측을 합쳐 2개로 세지 않는다.
- 관측끼리 공유하는 원본 이미지 수, 관측 간 각도, 같은 predictor/pose graph 사용을 기록한다. 후보와의 source 분리는 관측 간 통계적 독립을 뜻하지 않는다.
- 새 KF 도착 시점에만 재평가한다. 종료 후 pose와 미래 관측을 사용하는 결과는 hindsight 진단으로 분리하며 진행 판정에 사용하지 않는다.

## 개발·평가 분리와 봉인

| 구분 | 용도 | 허용 범위 |
|---|---|---|
| 기존 office0/E2 | 개발·실패 원인 분석 | 이미 확인한 데이터로 명시; 새 독립 평가로 재사용하지 않음 |
| 개발 장면/구간 | 점수 정규화·관측/충돌 기준·운영점 선택 | GT normal 라벨을 이용한 임계값 보정은 이 단계에서만 허용 |
| 별도 평가 장면 | 주 임계값 전이 검증 | 설정 고정 후 입력 RGB를 시간순 증거로 사용; GT는 사후 평가 전용 |
| NVS held-out RGB | E3 이후 렌더링 평가용 예약 | 후보 생성·관측 증거·정규화·임계값 선택에 사용 금지 |

주 검증에는 **최소 1개 개발 장면과 다른 1개 평가 장면**을 사용한다. 이는 한 번의 장면 전이 검증이며 폭넓은 일반화나 장면 간 유의성을 입증하지 않는다. 같은 장면의 시간 분할만 확보하면 보조 파일럿으로 보고하고 주 전이 검증 완료로 처리하지 않는다. 시간 분할도 후보·관측의 source image/pair가 개발·평가 경계를 가로지르지 않도록 하고, 경계 제외 구간과 평가 시작 시 관측 상태를 고정한다.

관측 가용성을 분석한 뒤 GT 평가를 열기 전에 다음 항목을 봉인한다.

- 개발/평가 장면·frame 범위·후보 목록, 평가 GT view/마스크/허용 오차 및 pose 민감도 arm
- 후보·관측 lineage, 관측 사용 가능 시각, 판단 snapshot/revision, 재평가 일정과 시퀀스 종료 처리
- 점수 방향·정규화·관측별 충돌 및 집계 규칙, 보호/veto 조건, 관측 부재·동점 처리
- 개발 임계값, 정상 보존 목표, 진행 기준, 비교 방법과 공통 집합, 설정/코드 hash

평가 GT를 보고 정규화나 임계값을 수정하면 해당 평가는 개발 자료가 된다. 수정한 방법의 전이 성능은 새로운 평가 분할에서 다시 확인한다. GT나 GT intrinsics/pose를 feature 추출에 넣지 않으며, GT-anchor 진단은 사후 평가로 분리한다.

## 점수 보정과 인과적 거부 진단

1. **기준 점수:** E2의 local-spacing 정규화와 고정 개발 임계값을 재현해 새 시퀀스의 실패/성공을 비교한다. 재보정한 운영점은 기존 E2 임계값을 그대로 적용한 arm과 구별한다.
2. **수정 점수:** 정규화 또는 불확실성 반영의 수정안은 개발 자료에서만 선택한다. 후보를 실제 bad/normal 라벨에 따라 다른 방식으로 정규화하지 않는다. 평가 구간의 점수 분포를 이용한 재보정은 주 실험에 허용하지 않는다.
3. **반복 충돌 점수:** P1 주 진단은 유효 관측별 signed front score 중 **두 번째로 큰 값**을 사용한다. 이 값이 임계값을 넘으려면 서로 다른 관측 2개 이상이 각각 임계값을 넘어야 한다. E2의 관측 중앙값/1-view 점수는 별도 진단이며 같은 방법이라고 섞지 않는다. 가림·유효한 반대 증거에 대한 보호 규칙도 개발 단계에서 고정한다.
4. **운영점 선택:** 주 목표는 정상 보존 99%, 95%는 보조 민감도다. 개발 normal 후보의 시간순 재평가까지 포함해 누적 오거부를 보정한다. 단일 snapshot의 99분위수만으로 여러 번 시험한 뒤의 정상 보존율을 보장한다고 가정하지 않는다. 임계값은 `score > threshold`인 경우만 거부하며 동점은 보존한다.
5. **판정 시점:** 해당 후보가 처음으로 반복 충돌 기준을 만족한 실제 snapshot에서 `would_reject`를 잠근다. 평가 라벨이나 결과 점수를 보고 가장 유리한 재평가 시점을 고르지 않는다. 끝까지 관측이 부족한 후보는 미판정으로 남긴다. 유효 개발 normal 표본이 없으면 임계값 미보정으로 기록하고 GO를 내리지 않는다.

B2 confidence, B6 depth, B7 RGB/NCC, B8 DoG와 P1을 같은 후보에서 비교한다. 방법마다 동일한 개발/평가 분할과 정상 보존 목표를 적용한다. B8은 중복 삽입 필요성 proxy이므로 기하 outlier 검출과 중복 억제를 구별한다. B8의 렌더 입력은 동일한 당시 원본 pre-map이며 미래/final Map을 사용하지 않는다. P1의 반복 충돌 점수로 바뀌는 효과와 정규화 변경 효과는 별도 arm으로 비교한다.

## 평가 지표와 분모

주 대상은 raw 전체 후보이며 원본 active 후보만의 결과도 별도 보고한다. 정상·불량·판정불명은 E1/E2와 같은 GT proxy 정의로 구별하고, 관측 가용성과 GT 판정 가능성을 혼동하지 않는다.

| 지표 | 정의 |
|---|---|
| 동시 2+ 관측 coverage | 같은 실제 snapshot에서 2+ 유효 관측을 확보한 후보 / 전체 후보. 생성 시점과 인과적 재평가 후를 분리 |
| 반복 관측 지연 | 생성부터 첫 2+ 유효 관측까지의 입력 frame/KF/시간; median/p95 및 끝내 미가용한 비율 |
| 전체 정상 보존율 | 거부하지 않은 GT normal / 전체 GT normal. 미판정 보존을 포함 |
| 관측 가능 정상 보존율 | 거부하지 않은 2+ 관측 가능 GT normal / 2+ 관측 가능 GT normal |
| 전체 bad recall | 실제 `would_reject`인 GT bad / 전체 GT bad |
| 관측 가능 bad recall | 실제 `would_reject`인 GT bad / 2+ 관측 가능 GT bad |
| 거부 정밀도 | 거부한 GT bad / GT 판정 가능한 거부. 거부 0개면 미정의 |
| 판정불명 거부 | GT ambiguous인 거부 후보의 수·비율. 정밀도 계산에서 제외하되 숨기지 않음 |
| 판별력·추가 이익 | 공통 후보의 AP·bad prevalence, 같은 정상 보존 제약에서 B2/B6/B7 대비 recall/정밀도 차이 |

P1 주 평가의 ‘관측 가능’ 집합은 평가 기간 중 한 번이라도 같은 snapshot에서 P1 유효 관측 2개를 확보한 후보로 고정하며, 실제 거부 여부와 무관하게 정의한다. 비교군의 score 가용 집합은 이 집합과 구별하고, 방법별 고유 집합과 공통 후보 집합을 함께 보고한다. 추가 관측 비용·후보별 재평가 횟수·판단 revision을 기록하되 실제 admission queue 메모리나 온라인 system latency 측정으로 부르지 않는다.

장면별 표본 수와 결과를 먼저 보고한다. 프레임·후보를 독립 반복 시행으로 간주한 통계적 유의성 주장은 하지 않는다. GT-anchor 및 두 pose의 공통 판정 진단에서는 라벨별 표본 수도 함께 보고하며, bad가 없으면 AP/recall은 미정의다.

## E3 진행 기준 — 새 평가 전 봉인할 계획값

다음 값은 **향후 검증을 위한 운영상 기준**이며, E2 측정값이나 보편적인 안전성 보장이 아니다. 평가를 열기 전에 설정으로 확정하고, 결과를 본 뒤 기준을 낮추지 않는다. 여러 평가 장면을 등록했다면 각 장면이 모두 충족해야 하며 합산 평균으로 실패 장면을 숨기지 않는다.

| 조건 | 주 평가 장면별 기준 |
|---|---|
| 인과성·출처·분할 무결성 | 미래/GT feature 유입, 후보 source overlap, 미확인 ancestry를 유효 처리한 사례 0건 |
| 반복 관측 확보 | 인과적 재평가 후 동시 2+ 관측 후보가 전체 raw의 **≥1%** |
| 반복 관측 집합의 GT 표본 | bad **≥100개**, normal **≥100개** |
| 정상 보존 | **전체 normal ≥99%**, **2+ 관측 가능 normal ≥99%** |
| 유효 불량 식별 | **전체 bad recall ≥1%**, **2+ 관측 가능 bad recall ≥5%**, **GT bad 거부 판정 ≥30개** |
| 전이 검증 | 장면이 분리된 평가에서 개발 단계에 봉인한 동일 규칙/임계값으로 달성 |

- **GO for E3 validation:** P1 반복 충돌 진단이 위 조건을 모두 충족한다. E3에서 실제 KEEP/REJECT/DEFER 정책과 geometry·coverage 손익을 검증할 준비가 됐다는 뜻이다. 연구 전체 GO가 아니다.
- **REVISE:** 관측 수/표본 부족, 정상 손실 초과, bad recall 미달 또는 거부 0개. 관측 확보·정규화·충돌 규칙을 개발 자료에서 재검토하고 새 평가로 확인한다.
- **파일럿 한정:** 같은 장면 시간 분할만 수행했다면 수치 기준을 충족해도 장면 전이 검증 완료로 보고하지 않는다.

정상 보존 99%는 해당 평가 표본에서의 관측 비율이며 모집단의 오거부 위험을 보장하는 수치가 아니다. Confidence/B6/B7 대비 추가 이익이 없으면 ‘기하 신호의 우위’를 주장하지 않는다. E2b 통과는 대조군 우위의 입증과 구별하며, E3에서는 confidence를 포함한 강한 대조군과 P1/P2/P3의 순증분을 필수로 검증한다. 실제 Map 삭제 뒤 품질·메모리·렌더링 보존은 이 단계의 판정 범위에 포함하지 않는다.
